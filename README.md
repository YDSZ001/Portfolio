# UI／交互设计作品集

这是一个可部署到 GitHub Pages 的静态作品集框架，包含首页、两个案例示例和一份可打印的简历模板。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 首页、项目卡片、自我介绍与简历入口 |
| `projects/flight.html` | 航拍任务管理案例，展示用户流程 |
| `projects/library.html` | 图书馆座位预约案例，展示组件与界面状态 |
| `resume.html` | 简历、公开联系方式和打印入口 |
| `assets/site.css` | 全站视觉样式和响应式布局 |

## 替换成自己的内容

1. 在首页更新署名、自我介绍、项目卡片和关于栏目。
2. 用真实项目替换示例内容，写清问题、个人职责、关键设计决定和验证过程。
3. 将作品图片放入 `assets/`，替换卡片及详情页的示例界面，并为有信息价值的图片填写替代文字。
4. 更新简历和公开邮箱。已有 PDF 时，可以把首页简历按钮链接到该文件。

## 本地运行与发布

在仓库根目录运行 `python -m http.server 8000`，然后打开 [本地首页](http://localhost:8000/)。

在 GitHub 仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，设置 **main / (root)**，点击 **Save**。部署完成后，可以在同一页面复制作品集网址。
